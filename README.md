# moonTool

在线工具集合 + 精选网站导航，全部免费使用，无需注册。

纯前端实现：所有工具在你的浏览器里跑，数据不上传服务器（少数需要服务端代发的功能会明确标注）。开源，MIT License。

- 工具一览：`/tools`
- 网站一览：`/sites`

## 网站导航

`/sites` 收录常用站点，卡片直接展示 favicon、描述与分类标签，点击新标签页打开。

站点分两类：

- **精选站点** —— 内置的固定内容，覆盖 AI 对话、开发平台、设计工具等方向
- **自建站点** —— 页面右上角「添加网站」可自行补充，填名称 + 网址即可。自建站点会出现在所有访客的列表里，删除需要管理密钥

## 隐私说明

大部分工具完全在浏览器本地运行，文件的读取、处理、生成都不经过服务器：

- 图片处理、EXIF、SVG、文件打包解压、哈希计算 —— 文件仅在内存中处理
- 加密解密、编码解码、JWT 解析、进制转换 —— 纯本地计算

以下功能需要网络请求，使用时请知悉：

| 功能 | 请求去向 |
| --- | --- |
| 网站卡片的 favicon | Google / DuckDuckGo / gstatic 图标服务 |
| 系统信息检测的 IP 与归属地 | ipapi.co、api.ipify.org |
| API 健康检测 | 由本站服务端代发到你填写的 API 地址 |
| 订阅转换 | 由本站服务端抓取你填写的订阅链接 |
| 自建站点 | 名称、网址等信息保存在 Vercel Edge Config |

## 使用

浏览器打开即可，无需安装、无需注册。

支持键盘操作与语义化标签，移动端自适应，具备亮 / 暗主题切换（右上角按钮，带圆形扩散过渡动画）。
